📚 Help Center & Installation Guide

Welcome to GoNetworkMonitor Enterprise v3.1.0

This guide will help you get started with network monitoring in minutes.

1
Select Network Interface

Choose your active network card from the dropdown at the top. Usually it's the one with an IP address starting with 192.168 or 10.

2
Start Capture

Click the "Start Capture" button. The dashboard will begin showing real-time traffic data.

3
Monitor & Analyze

Watch the KPI cards, charts, and tables update in real-time. Check the AI Intelligence tab for anomaly detection.

Windows Installation & Setup

1
Install Npcap (Required)

⚠️ CRITICAL: Download and install Npcap. During installation, MUST enable "Install Npcap in WinPcap API-compatible Mode".

Without this, the program cannot capture network traffic!

2
Run as Administrator

Right-click gonetmon-v3.1.0-windows-amd64.exe → Select Run as Administrator.

3
Allow Firewall Access

If Windows Firewall prompts, click Allow Access to permit network monitoring.

4
Open Dashboard

Open your browser and go to http://localhost:8080. You're ready to monitor!

Enterprise Features

🤖 AI Intelligence

Automatic anomaly detection using statistical analysis. Detects DDoS spikes and unusual traffic patterns.

💾 Persistent Storage

All data is saved to SQLite database (network_monitor.db). Historical data survives application restarts.

Export metrics to Grafana, Datadog, or any Prometheus-compatible monitoring stack via /metrics endpoint.

Live packet capture, protocol analysis, connection tracking, and bandwidth monitoring.

Common Issues & Solutions

❌ "No interfaces found"

Solution: Ensure Npcap is installed with WinPcap mode enabled. Restart the application as Administrator.

❌ Dashboard won't load

Solution: Check if port 8080 is already in use. Edit config.json and change the port number.

❌ No traffic data showing

Solution: Select the correct network interface (usually the one with your IP address). Generate some network traffic (open a website).

❌ Permission denied error

Solution: Always run as Administrator. Network packet capture requires elevated privileges.
